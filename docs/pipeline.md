# Процесс: от темы до готового ролика

Проверен на ролике 01. Каждый шаг — точка, где пользователь может вмешаться. Движок: OpenMontage (пайплайн `animated-explainer`, режим **atelier**, рендер **Remotion**).

## 0. Правила OpenMontage
Перед работой читать `OpenMontage/AGENT_GUIDE.md`. Главное: производство идёт через пайплайн, решения о провайдере, движке и режиме озвучиваются пользователю заранее, подмены без согласия нельзя. Если доступны и Remotion, и HyperFrames, обязательно показать оба и дождаться выбора (в серии выбран Remotion: точные цифры и счётчики).

## 1. Тема и ресёрч
- Предложить 2–3 темы, пользователь выбирает.
- Ресёрч через WebSearch на русском и английском. Записывать **источник каждой цифры**.
- Пометить, какие данные из первоисточника, а какие из вторичных пересказов. Вторичные требуют сверки перед публикацией.

## 2. Три концепции и план
- Показать 3 концепции (идея, визуальный образ, плюс/минус), дать рекомендацию.
- Сразу зафиксировать: язык, длина (30 с), формат 1080x1920 (9:16), 30 fps, режим atelier, движок, голос, музыка.
- Atelier: композиция пишется с нуля под тему, без шаблонных сцен. У каждой сцены свой главный визуальный объект.

## 3. Арт-дирекшн и сценарий
- `art-direction.md`: design read, три «ручки» (visual_variance, motion_intensity, information_density), палитра, шрифты, signature device, таблица сцен (время, главный объект, композиция, моушн).
- Сценарий по шаблону шаблону сценария проекта (`<проект>/templates/script-template.md`). Бюджет слов: 30 с ≈ 60–70 слов при уверенном темпе.
- Сценарий и текст для озвучки согласовать **до** записи/синтеза.

## 4. Озвучка
Предпочтительно: **записывает сам пользователь** (живой голос, лучше Piper). Тогда: прислать чистый текст, попросить паузы 1–2 секунды между абзацами, формат любой. Дальше см. [audio-recipes.md](audio-recipes.md): конвертация, расшифровка с таймингом слов, шумодав.
Запасной вариант: синтез Piper (`ru_RU-ruslan-medium`).

## 5. Привязка сцен к голосу
Тайминги слов из расшифровки → границы сцен и субтитры. Голос в миксе сдвинут на **+0,3 с**, чтобы первый кадр не начинался вровень с речью. Ключевые цифры в кадре должны появляться в момент, когда их произносят.

## 6. Сборка композиции
- Файл `index.tsx` лежит **физически** в `OpenMontage/remotion-composer/projects/<slug>/` (симлинк ломает поиск node_modules).
- Копия-источник правды: `OpenMontage/projects/<slug>/index.tsx` и архив в `<проект>/videos/NN-slug/composition.tsx`. После правок копировать в оба места.
- Проверка кадров: `npx remotion still ... --frame=N --bundle-cache=false`, затем склеить контактный лист (скрипт `scripts/contact_sheet.py`) и посмотреть глазами. Проверять наложения текста, выход за safe zones.

## 6a. Motion и звук (конвейер с motion удержания)
Тайминги анимации и звука берутся из **якорей по словам голоса**, поэтому смена озвучки не требует правки кода:
0. (по желанию, для живой записи) `scripts/tighten_voice.py <slug>` сжимает паузы длиннее 0,5 с до 0,32 с и пересчитывает слова; оригинал сохраняется в `raw_orig.wav`/`words_orig.json`. Запускать ПОСЛЕ transcribe.
1. `scripts/transcribe.py <slug>` расшифровка голоса (`assets/audio/human/raw.wav`) со словами и временем.
2. `scripts/build_timing.py <slug> <проект>/videos/NN-slug 0.3` выравнивает слова СЦЕНАРИЯ (`spoken.txt`) по расшифровке (устойчиво к ошибкам распознавания), создаёт `timing.json` (слова и якоря из `anchors.json`, подмена чисел через `display.json`).
3. Композиция читает `timing.json` (`import timing from "./timing.json"`), сцены и всплывающие элементы привязаны к якорям.
4. `scripts/make_sfx.py` (один раз) создаёт звуки в `<проект>/sfx/` и бодрую музыку (`make_sfx.py music 30`).
5. `<проект>/videos/NN-slug/sfx.json` описывает звуковые события по якорям.
6. `scripts/render.sh <slug> <CompositionId> silent.mp4`, затем `scripts/mix_video.py <slug> <проект>/videos/NN-slug <голос.wav> [музыка] silent.mp4 final.mp4` (голос, SFX, музыка с приглушением, нормализация, замеры).
Для черновика без живой записи можно озвучить Piper и пройти те же шаги.

## 7. Рендер, микс, финал
- Рендер немого видео: `scripts/render.sh <slug>`.
- Микс и муксинг: `scripts/mix_human_voice.sh <slug>` (шумодав, пульс музыки с приглушением под голос, нормализация −14 LUFS).
- **Проверка звука замерами** (окна с речью против пауз). Сначала проверить, потом присылать.
- Отправить пользователю через SendUserFile.

## 8. Пакет публикации (обязателен для каждого ролика)
(Для роликов 02+ обложка рендерится композицией `Cover` из `brand.tsx`, см. design-system.md.)
Ролик отдаётся только вместе с пакетом, см. `<проект>/templates/publish-package.md`:
1. **Обложка:** композиция `Cover` в `index.tsx`, рендер `npx remotion still ... Cover ../projects/<slug>/renders/cover.png`. Ключевое в центре кадра (профиль режет до 3:4 и 1:1).
2. **Название** (основное + 2–3 альтернативы), **описание**, **хештеги**.
3. **Ссылка на канал проекта** в описании каждого ролика (адрес в brand.md проекта).
4. Собрать папку `ready/NN-slug/` (`final.mp4`, `cover.png`, `publish.md`).
5. Прислать пользователю видео и обложку файлами, а название, описание и хештеги текстом в ответе.

## 9. До публикации
- [ ] Сверить каждую цифру с первоисточником, поправить, если расходится.
- [ ] Логотип и цвета бренда, если появились.
- [ ] Метка ИИ по правилам платформы, если нужна.
- [ ] Записать итог в `<проект>/videos/NN-slug/README.md`.
