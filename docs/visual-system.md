# Визуальная система вертикальных роликов

> Дизайн-система (палитра, шрифты, компоненты) живёт в папке проекта. Здесь только общие правила раскладки.

Формат: **1080x1920, 30 fps, 30 с**, видео h264 (CRF 18), звук AAC 192k 48 кГц.

## Токены
Цвета и шрифты берутся из дизайн-системы проекта (`design/brand.tsx` в папке проекта), не придумываются заново. Один акцент, без градиентов; главное выделяем контрастом.

## Правила
- **Простота важнее красоты** (см. simplicity-rules.md). Показываем сам предмет (сам документ, сообщение), а не метафору. Главная мысль ролика написана крупным текстом на экране и повторена в конце.
- **Счётчики не начинают с 0.** Если превью платформы поймает кадр «+0%», зритель не поймёт. Анимировать число так, чтобы любой кадр был читаем сам по себе (старт с итогового значения или с осмысленного).
- **Обложка обязательна и ставится вручную** (`cover.png`).
- **Одна идея и одна цифра на сцену.** Плотность информации низкая (3 из 10), моушн средний (6), вариативность 6.
- **У каждой сцены свой главный визуальный объект.** Не повторять одну и ту же композицию с разным текстом. Фирменный приём показывать в 1–2 моментах, не в каждой сцене.
- Текст не мельче 48 px. Цифры очень крупно (200–700 px).
- Движение: пружины с перелётом (`spring`, damping 8–14) для карточек, ease-out для цифр. В одном ролике минимум 3 разных easing.
- Детерминизм: никакого `Math.random()`, только `random(seed)` из Remotion (иначе мерцание между кадрами).
- Переходы между сценами разные, но жёсткие и быстрые (0,3–0,5 с).

## Safe zones для вертикали
Верх (до ~y 250) и низ (с ~y 1580) закрыты интерфейсом TikTok/Reels. Ключевое держать в зоне y 250–1580. Исключения: мелкий источник данных наверху (y ~80), крупные элементы не заходят в низ.

## Субтитры (вшитые)
- Позиция: верх y = 1490, по центру, отступы по бокам 70 px.
- Плашка `rgba(14,15,18,0.78)`, радиус 26, Onest 700 / 64 px, до 2 строк.
- Блоки 2–4 слова, ключевые слова (цифры, имя бренда, главная мысль) лаймом.
- Появление: прозрачность + подъём на 18 px + лёгкий scale за ~5 кадров.
- Тайминги **из расшифровки слов**: `from` = старт первого слова блока +0,3 с (сдвиг голоса) −0,04 с; `to` = min(начало следующего блока, конец последнего слова +0,35 с).
- Не дублировать финальный призыв: если «Найди работу быстрее» крупно на экране, субтитр для этой фразы не ставим.

## Приёмка кадров
Перед полным рендером сделать `still` ~8 кадров в моменты речи, склеить в контактный лист, проверить: нет наложений текста, всё читаемо, ничего не вылезает за кадр. Нашли дубли текста: убрать лишний.
