# shorts-ideas: идеи и сценарии для шортсов

Цель: не «10 банальных тем», а несколько идей, из которых хочется сразу снимать. Работает вместе с хабом `video-stack` и `docs/simplicity-rules.md` (одна идея, польза за 3 с, пример вместо статистики, тест «друг»).

## 0. Вводные (спроси одной короткой репликой, чего нет)
Тема или ниша; для кого (возраст, что болит); тон (серьёзный, смешной, дерзкий); платформа; есть ли голос на камеру или только закадровый; CTA (куда вести). Нет ответа: выбери очевидное, скажи что выбрал, иди дальше. Сообщения пользователя часто обрываются: не гадай, переспроси коротко.

## 1. Генерируй широко, потом режь
1. Выдай **15–20 сырых идей** по углам из списка ниже (не показывай пользователю весь сырой список, только отобранные).
2. Прогони каждую через фильтры (раздел 3). Оставь **5**. Из них отметь **главную** и объясни одной фразой, почему она зайдёт.

### Углы (каждый даёт другую идею из одной темы)
| Угол | Формула |
|---|---|
| Ошибка | «Ты делаешь X неправильно, вот из-за чего» |
| До/после | Реальный пример «было → стало» на экране |
| Миф | «Все думают A. На деле B» (только если можно показать доказательство) |
| Секрет/лайфхак | Один приём, который работает за 10 секунд |
| Сравнение | «Плохой пример vs хороший», зритель сам угадывает |
| Мини-история | «Со мной было…», один конфликт и вывод |
| Вопрос-угадайка | Зритель думает до ответа, ответ в конце |
| Список-обратный | «3 вещи, которые я бы не делал, если бы начинал снова» |
| Реакция/разбор | Разбираю чужой пример (своё, не чужой контент) |
| Серия | «Часть 1 из 5», каждая часть сама по себе понятна |

## 2. Что делает идею интересной
- **Конкретика**: реальная фраза, реальный текст, реальная сумма, а не «многие люди».
- **Напряжение**: зритель чувствует «я тоже так делаю» или «мне это надо знать».
- **Разрыв ожидания**: ответ не такой, как думал зритель.
- **Личная польза**: зритель уносит одно действие.
- **Узнаваемость**: тема из жизни аудитории, а не из учебника.

## 3. Фильтры (идея проходит, если «да» на все)
1. Одна мысль объясняется одной фразой 12-летнему (тест «друг»)?
2. Хук и польза умещаются в первые 3 секунды?
3. Есть конкретный пример, который виден на экране без объяснений?
4. Понятна без звука (главная мысль крупным текстом)?
5. Есть действие в конце?
6. Влезает в 20–35 секунд?
7. Не повтор прошлых роликов проекта (посмотри `videos/` проекта)?
8. Нет цифр без источника; нет медицинских/юридических/финансовых обещаний; нет чужого контента без прав.

## 4. Хуки (первые 3 секунды)
Для каждой отобранной идеи дай **3 варианта хука**, лучший отметь. Типы:
- Ошибка: «Из-за этой строчки тебе не отвечают».
- Обещание: «Через 20 секунд перепишешь своё резюме лучше».
- Конфликт: «Я думал, это работает. Нет».
- Вопрос с подвохом: «Какая из этих двух фраз сильнее?»
- Шок-факт, но только с источником («Данные: …»).
Правила: первое слово по делу, без «Привет, ребята», без представления. В кадре что-то происходит с 0-го кадра. Открытая петля до 4 с (обещай ответ, который будет в конце).

## 5. Формат выдачи
Для каждой из 5 идей:
```
N. Название (угол)
Мысль: одна фраза.
Хук (0–3 с): ...  | запасные: ... / ...
Пример на экране: ...
Конец / действие: ...
Почему зайдёт: ...
```
Потом: «Рекомендую №X». Спроси, какую делать. Не пиши все сценарии сразу.

## 6. Сценарий выбранной идеи (30 с)
Таблица по секундам: время | текст голоса | что в кадре | крупный текст.
Структура: **0–3 хук → 3–8 проблема/открытая петля → 8–24 пример и решение (событие в кадре каждые 1,5–2,5 с) → 24–30 вывод + действие, возвращающий хук**.
Текст озвучки: короткие фразы, разговорный русский, числа словами, бренд кириллицей. Потом тест «друг». Затем передай в скилл `voiceover` и в сборку по `docs/pipeline.md`.

## 7. Пакет публикации (идея не готова без него)
Название (до 60 знаков, с ключом), описание 2–3 строки, 3–5 хештегов, текст обложки (3–5 слов), ссылка на канал, метка ИИ, если голос синтетический или контент реалистичный ИИ.

## 8. Контент-план
Если просят план: серия из 7–10 роликов, 2–3 разных угла, каждый ролик самостоятельный; повторяющийся формат узнаётся (одна рамка, один стиль, один зачин).

## Чего не делать
Не копировать чужие ролики и их названия. Не придумывать статистику. Не выдавать список из 20 пунктов: отобранные 5 и рекомендация.
